## Глобальные слои кабинета
Сайдбар (история, закреплённые, поиск) · ⌘K-терминал · Входящие (уведомления) · Боковая панель результата
(слайды, документы, код, превью) · Тосты «Входящее» · Режим подсказок `Alt` · Плашка потери связи.

## Дизайн-система экранов

Все внутренние экраны используют две темы:

- **Night Ops:** тёмный industrial workspace, bone text, graphite panels,
  radio-lime для подтверждения/выбора/запуска, signal-magenta для live/media/
  ошибок. Cyberpunk 2077 остаётся как материал, ритм, свет и системность, но
  не как игровой HUD.
- **Paper System:** светлая техническая бумага, ink text, violet secondary,
  radio-lime actions. Это отдельная бумажная система, а не инверсия Night Ops.

Экран не считается готовым, если в нём нет понятного доминирующего объекта,
реального состояния системы, hover/focus/touch состояний, reduced-motion
поведения, пустого/загрузочного/ошибочного состояния и проверки 375px + wide
desktop.

## Критические пути
1. **Первый запрос:** лендинг → регистрация → подтверждение → вход в систему → «для чего вам KURAI» → выноски → запрос → ответ.
2. **Нет кредитов:** запрос → «недостаточно кредитов» (штриховка) → пополнение → транзакция по шагам → награда → повтор запроса.
3. **Медиа в чате:** текст → режим «Изображение» → генерация → «Оживить» → видео в очереди → другой чат → «Входящее: видео готово» → открыть.
4. **Сбой модели:** запрос → задержка → маршрут `›` → резервная модель → ответ, за сбой не списано.
5. **Агент:** режим Research → выбор реплики → журнал заданий + сеть источников → итог работы → отчёт в боковой панели.
6. **Возврат пользователя:** публичный чат по ссылке → «Попробовать KURAI» → регистрация.

## Порядок сборки (секции мастера)
1. Каркас кабинета: сайдбар, единый чат-шелл, ⌘K, реальные hover/motion
   состояния, Night Ops / Paper System tokens.
2. Главная кабинета Command Deck: composer, рецепты, workspace signal,
   модель/стоимость/режим до отправки.
3. Единый чат: стриминг, режимы, медиа-карточки, ветки, агенты, контекстный
   rail, receipt, источники, действия ответа.
4. Model Bay: выбор модели, Auto router, сравнение, цены, избранное,
   недавние, режимы OpenRouter.
5. Медиатека: provenance, variants, animate/reuse/download, asset inspector.
6. Баланс и тарифы: balance hero, top-up, ledger, calculator, refunds.
7. Настройки и профиль: appearance, calm mode, default model, data export,
   deletion policy, legal links.
8. Вход, регистрация, вход в систему.
9. Служебные: 404, статус, changelog, юр. страницы, публичный чат.
10. Backend production lane: model registry, quote/run/events, ledger,
    payments, retention/deletion jobs, provider fallback policy.
