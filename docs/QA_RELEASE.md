# Проверка фаз 12–13: адаптивность, доступность, сборка

Дата: 8 октября 2026. Ветка `frontend/design-system`.

## Что проверено

| Проверка | Охват | Итог |
|---|---|---|
| Ширины | 375, 768, 1024, 1280, 1680 px — 10 экранов кабинета и 12 публичных | горизонтального переполнения страниц нет |
| Темы | Night Ops и Paper для всех экранов кабинета | обе проходят контраст |
| Аудит axe (WCAG 2.2 AA) | кабинет на 375 и 1280 px в обеих темах, публичные на 375 и 1280 px | 0 нарушений |
| Зоны нажатия | телефон, все интерактивные элементы | не меньше 24 px; основные — 44 px на касании |
| Клавиатура | главная → отправка → ⌘K → выбор модели → Esc | фокус виден, есть «Перейти к рабочей области», Esc закрывает окна |
| Уменьшенное движение | системная настройка и спокойный режим KURAI | остаются только плавные появления без сдвига |
| Сборка | `next build` с адресом API | без ошибок и предупреждений |

## Что нашлось и исправлено

- Переполнение по ширине на «Проектах» (на 42 px) и «Балансе» (до 203 px): у элементов сетки не было `min-w-0`, колонку растягивали поле инструкций и график расходов.
- Таблица моделей не помещалась даже на 1280 px: описания из каталога OpenRouter содержали Markdown-ссылки с длинными адресами. Описания теперь чистый текст, длинные слова переносятся.
- Журнал операций не помещался в свою колонку на любом экране — минимальная ширина таблицы подогнана.
- Контраст третичного текста 4,03–4,27:1 на приподнятых поверхностях — токены `ink3` (обе темы) и фиолетовый в Paper подняты до ≥ 4,6:1.
- Неверная разметка списка в профиле (`dl`), ссылки в тексте входа и регистрации без подчёркивания, таблица лендинга без доступа с клавиатуры.
- Счётчики-табло (баланс, цена) не озвучивались: цифры были скрыты от диктора, а подпись на `span` запрещена. Значение теперь читается.
- Нет ссылки «пропустить меню» — добавлена, видна при фокусе.
- Спокойный режим включался только после загрузки скриптов, и первые мгновения анимации успевали идти — теперь он применяется до первой отрисовки.
- Мелкие зоны нажатия: код ответа, «История списаний», ссылки подвала, «Забыли пароль?», ползунки настроек, кнопка «Таблица».
- Склонение: «1 веток», «0 таких ответа», «3 разделов», «1 работ», текст согласия при регистрации.
- Предупреждение сборки про `::highlight()` — правило подсветки озвучки вынесено во встроенный стиль.

## Что не входило или осталось

- Скриншот-ревью против эталона Workbench: эталонного макета в репозитории нет.
- Вынос текстов интерфейса в файлы локализации — по плану нужен перед английской версией.
- Независимое финальное ревью визуала и безопасности — не проводилось.
- На телефоне таблицы моделей, журнала и сравнения на лендинге прокручиваются вбок — это задумано; области доступны с клавиатуры.
- Внутри `<main>` чата есть 23 px невидимого выхода за край; страница вбок не прокручивается, пользователю не видно.
