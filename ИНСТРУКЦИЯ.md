# Как пользоваться фронтендом KURAI

## Запустить на компьютере
1. Открой папку `frontend` в терминале
2. `npm install` (только первый раз) → `npm run dev` → открой http://localhost:3000
   (в этой среде dev-сервер работает на порту 3100: `.claude/launch.json`)
3. Проверки: `npm test` (логика), `npm run typecheck` (типы), `npm run lint`, `npx next build` (сборка)

## Что где открыть
| Адрес | Экран |
|---|---|
| `/` | Лендинг |
| `/pricing` | Тарифы и калькулятор |
| `/login`, `/register`, `/reset` | Вход, регистрация, сброс (пароль `wrongpass` покажет ошибку входа) |
| `/app` | Главная кабинета (первый раз — знакомство) |
| `/app/c/7f3a` | Единый чат (в автономном прототипе показан демонстрационный поток; при подключённом API — настоящий серверный поток) |
| `/app/media`, `/app/billing`, `/app/settings`, `/app/profile` | Медиатека, баланс, настройки, профиль |
| `/s/7f3a` | Публичный чат по ссылке |
| `/status`, `/changelog`, `/terms`, `/privacy`, `/offer` | Служебные страницы |
| `/kit` | Витрина дизайн-системы (только для разработки) |

## Где что лежит
- **Цвета, шрифты, размеры, длительности:** `frontend/src/app/globals.css` (блок `@theme`) и описание в `DESIGN.md`
- **Кибер-эффекты (примитивы):** `frontend/src/components/fx/`
- **Тексты экранов:** прямо в страницах `frontend/src/app/**/page.tsx` и компонентах `frontend/src/components/**`
- **Автономный прототип:** `frontend/src/mocks/` — нужен только если API не настроен.
- **Рабочий клиент API:** `frontend/src/lib/kurai-api.ts`; он подключается при наличии `NEXT_PUBLIC_KURAI_API_BASE_URL`.
- **Договор отображения:** `frontend/src/types/api.ts` (форма данных) и `frontend/src/lib/stream.ts` (события потока ответа).

## Частые правки
- **Поменять акцентный цвет:** `--color-acc` в `globals.css` — перекрасится весь продукт
- **Поменять цены тарифов:** `frontend/src/lib/pricing.ts` (`PLANS`)
- **Добавить модель в режим:** `frontend/src/lib/modes.ts`

## Подключение бэкенда
Запустите Django API на `http://localhost:8000` и добавьте в `frontend/.env.local`:

```bash
NEXT_PUBLIC_KURAI_API_BASE_URL=http://localhost:8000
```

Рабочий поток использует cookie-authenticated SSE с восстановлением по
`Last-Event-ID`. В подключённом режиме интерфейс показывает только возможности,
которые сервер объявил в `/api/v1/capabilities`; видео, аудио и платежи не
маскируются под готовые интеграции.

## Проще всего
Открой проект в Claude и скажи обычными словами, что поменять — запустится режим правок мастера.
