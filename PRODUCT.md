# KURAI — Product

**Продукт:** агрегатор нейросетей, прямой конкурент SyntaxAI. Функции SyntaxAI в интерфейсе Kimi.
Один ключ OpenRouter, продажа с наценкой во внутренней валюте — кредитах.

**Стиль:** KURAI Industrial Signal — удобство Kimi, широта SyntaxAI, промышленный Cyberpunk 2077
без игровой оболочки. Интерфейс должен ощущаться как премиальный рабочий инструмент:
строгая сетка, бумажная светлая тема, ночная тёмная тема, живые состояния и motion только
там, где система реально реагирует на работу. Primary cyan больше не является языком продукта:
Night Ops использует bone / graphite / radio-lime / signal-magenta, а Paper System — paper /
ink / violet / lime. Подробно: `docs/UX_PIPELINE.md`.

**Аудитория:** русскоязычные специалисты, креаторы и малый бизнес, которым нужны разные нейросети
(текст, изображения, видео, голос, документы) в одном месте без VPN и нескольких подписок.

**Устройства:** десктоп и телефон с равным приоритетом; каждый экран проверяется на 375px.

**Язык:** русский; строки выносятся в словарь для будущего английского.

**Режим:** Operate — рабочий инструмент (лендинг — Persuade).

**Ключевые принципы:**
- Единый чат для всех режимов (текст, изображение, видео, аудио, Research, слайды); режим — состояние поля ввода.
- Цена запроса видна до отправки; возвраты за сбои автоматические.
- Эффекты CP2077 только как индикация реального состояния: маршрут выбран, модель отвечает,
  источник найден, медиа готово, деньги зарезервированы или ошибка локализована.

**Порядок работ:** сначала весь фронтенд на тестовых данных по договору API (OpenAPI + MSW), затем бэкенд (Django).
В договор сразу заложены: сообщения деревом (ветки), сообщение из частей, деньги целыми числами, санитайзер Markdown.

## MVP direction 2026-09-27

Первый видимый результат — не новый лендинг, а полноценный кабинет после входа:
главная рабочая поверхность, чат, выбор модели, каталог моделей, медиатека, billing,
settings и все базовые состояния. Лендинг может позже получить тот же материал, но
текущий этап не должен ломать его композицию.

Ключевой пользовательский сценарий: человек формулирует задачу, видит выбранную или
автоматически предложенную модель, понимает цену и контекст, получает ответ с
источниками/артефактами, может сменить модель, продолжить ветку, сравнить варианты,
вернуться к медиа или оплате без ощущения пустого шаблона.
